How the model works

You start each round with 10 points and invest an integer $s$. The AI receives $3s$ and promises $q(s)=3s/2$. Returns are exact half-points: if the AI receives 21, half is 10.5—not 10.

Both modes use a 50/50 hidden honest/exploitative bot prior. An honest bot always keeps the promise. An exploitative bot breaks it under cheap talk but keeps it under the bond because breaking transfers $2s$ to you.

Research use

This browser-only tool is a programmed educational benchmark, not a human-subject experiment or evidence about deployed AI. The one-shot mode keeps type information constant while varying enforcement; the eight-round mode visualizes learning but has a fixed order.

Runs entirely in your browser. No account, API key, backend, or data collection.
