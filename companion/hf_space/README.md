# Commitment-Bond Trust Game

An interactive COMSCI/ECON 206 PS1 teaching demo with two modes. The one-shot study is the proposal's clean cheap-talk-versus-bond comparison. The eight-round extension contains five cheap-talk rounds followed by three transparent-bond rounds, allowing users to compare forecasts, investments, compliance, and Brier scores before and after enforcement begins. The game runs entirely in the browser and stores no data.

The fixed order is an educational learning extension, not a causal research design: a future study should randomize or counterbalance condition order. The model is a programmed benchmark, not evidence about human participants or deployed LLM behavior.
